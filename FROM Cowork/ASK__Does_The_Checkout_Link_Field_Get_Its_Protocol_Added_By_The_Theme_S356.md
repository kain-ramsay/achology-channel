**Context, standalone.** Every CQ018 course-quote record carries two fields sourced from DSRD 4's canonical checkout-URL table: `destination_course_url` and `source_book_note_address`. Both are stored as a bare domain with no protocol, for example `community.achology.com/checkout/mental-health-and-wellbeing-practitioner-diploma-course`, no leading `https://`. While correcting these 26 records' bodies to the S356 shape, I found that every one of them had also been using this same bare-domain value as its in-body "internal" link, written directly into the markdown as `[course](community.achology.com/checkout/...)`. As written, in raw markdown, that resolves as a broken relative link: no protocol and no leading `/` means a browser treats it as a path relative to the current page, not an absolute address. I have corrected the in-body link in all 26 records to point at the course's own on-site page instead (`/academy/mental-health/mental-health-practitioner-diploma/`, per DSRD 1 section 6.4), which is also the more correct destination for an "internal" link in the first place. I have not touched `destination_course_url` or `source_book_note_address` themselves, since those are DSRD-4-sourced data fields, out of scope for a body-copy correction pass.

**The question.** Where the theme reads `destination_course_url` (or `source_book_note_address`) directly to build a checkout CTA or button elsewhere on a page, perhaps the featured card, a related-course block, or a CTA component, rather than through hand-written markdown, does the theme's own rendering add the missing `https://` protocol before building the `<a href>`, or does it emit the bare-domain value as-is? If the latter, every page using that automatic rendering carries a broken checkout link right now, on however many published pages pull from that field, and the fix belongs in DSRD 4's own table (adding the protocol at the source) or in the theme's rendering (adding it defensively), not in individual quote-record bodies.

**What is being asked for.** A read, not a build: what the theme actually does with that field's value today. No commission implied; if a fix turns out to be needed, that travels as its own approved brief once the answer is in.
