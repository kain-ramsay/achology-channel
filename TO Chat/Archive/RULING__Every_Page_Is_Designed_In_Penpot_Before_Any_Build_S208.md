# RULING: every page is designed in Penpot before any build (Kain, 3 November 2026)

**Kain's words.** "There will be no more designing as we build ... This ends right now ... A page will never get developed or designed from scratch through us just talking about it anymore ... we need a permanent solution for actually designing pages ... not inside of code." It must be free or cost effective. Then, on the tool: "Yes, Penpot".

**The ruling.**
1. No page, block or component is designed by talking it through or by building guesses in code. Every look is designed in Penpot first, as whole pages at computer and phone width.
2. Kain sees and signs the design in Penpot. That signed frame is the spec. No signed frame, no build.
3. Every Penpot design uses only one Achology library built from DSRD 7 (colours, Como and Mulish, the registered type styles, the spacing scale) and the signed components. A part with no registered style stops and is put to Kain before it is drawn.
4. Code builds the signed frame exactly, reading the file through Penpot's own connector, and compares the built page against the frame before Kain looks.
5. Words and structure may still be agreed in words first (as the course page's ten blocks were); the look never is.

**Companion ruling, same sitting (2 November 2026):** build only through the design standards, every font, weight, size, line height and space from DSRD 7's register, from the first line. Kain asked after Code found four parts of the signed course hero off the register: the figures and their words on line heights the register does not hold, the promise lines on a weight with no row at 14, and the hero button's size (already Chat's to write into DSRD 7 section 5.1).

**Why Penpot.** Free with no limits on files or connector use; Penpot's own hosted connector lets Code read and draft into the file. Figma's free connector is capped at a few calls a month; Pixso is young; Lunacy has no connector; Claude's own canvas is not outside Claude, as Kain asked.

**State.** Kain made the free Penpot account, switched the connector on and added it to Claude as a custom connector. Not yet tested (the connector loads in a fresh session). Next: test, build the library, then design the course page in Penpot from its ten agreed blocks.

**What this replaces, for Chat to judge:** the four rendered options in the shared Change Viewer as the way a new page or block is designed (The Harness Rule 7, Project Instructions section 5). Whether options rounds survive inside Penpot for refinements is Kain's call; Code has not put it to him.
