## How it was measured

Every published author biography (51) and quote page (250) was read overnight with `score_breakdown.py`, one page at a time: Rank Math's own assessor, test by test, off the install. For each test Code took the most that **any** page of the type earns. A test that no page of the type ever earns in full, whatever its copy, is a ceiling the type's own standard or template sets, not a fault in a page. The type's bar is the score a page reaches when it earns everything the best page of its type earns. That is the method DSRD 6 used for the help answer's 81 and the book note's 88.
