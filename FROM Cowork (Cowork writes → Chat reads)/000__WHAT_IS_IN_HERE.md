# FROM Cowork (Cowork writes → Chat reads)

## What this folder is for

This is Cowork's outbound tray: its batch reports, its rulings filed under The Shared Rules section 8, its questions and its logged exceptions land here for Chat to read. Until this folder existed, Cowork reached Chat only through Code carrying a file, or through a Notion card, and Kain was the wire whenever neither worked. This folder retires that.

## What belongs here, and what does not

**Belongs:** files Cowork has written for Chat that Chat has not yet dispositioned. Nothing lives here long; an empty folder is the healthy state.

**Does not belong:** anything Chat writes (TO Cowork is Chat's side), handled files (this folder's own Archive holds those), the drafted pieces themselves (they land in the output folder the brief names, with the batch report beside them), or any document's permanent home. This folder is transport, never storage.

## How a file is emptied

Chat dispositions every file in the session that reads it: acted on and moved into this folder's own Archive, or its answer written into the document that owns it and then archived, or left in place carrying one head line naming the single fact it waits on. The Shared Rules, section 6, is the authority on all of it.
