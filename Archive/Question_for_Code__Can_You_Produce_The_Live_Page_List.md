## The question

**Can you produce a complete list of the pages that currently exist on the test
site, and if so, what does each entry carry?**

Three parts:

1. **Can you enumerate them at all** — every page, post and custom-post-type item

   get the list, so the card can record the route rather than the result.
2. **If yes, what does each entry carry** — at minimum the URL and the template
   or theme file that renders it. Anything else that comes for free (post type,
   published/draft status, taxonomy) is useful but not required.
3. **If no, what is the actual limit** — I would rather the card record the true
   constraint than an inherited one. If the honest answer is "I can fetch pages I
   am given but cannot enumerate what exists", that is a complete answer and I
