# RULING: the workbook design is settled. Build every workbook to the template file, not to a description of it.

**DOCUMENT TYPE:** ruling, from Claude Chat, Session 345. **Date:** 6 September 2026.
**Ruled by:** Kain, in the S345 sitting, on a rendered nine-page document set in real Como. Every decision below was made by him looking at the page, not reading about it.
**Applies to:** every Achology workbook, all 24 and any after them. Also to Data Labs, whose pack carries a snapshot of the workbook standard.
**Read this cold.**

---

## 1. What changed today, in one line

**A workbook now has a design, and it is a file rather than a description.**

Until today the workbook standard said what a workbook contains and how long each part runs, and nothing about how it looks. Kain's own master template existed but had never been joined up with the standard, so the approved exemplar was plain typed text. That gap is closed.

## 2. The three things that now exist, and which one wins

1. **The approved template file.** `06__WORKBOOK_TEMPLATE__Achology_Master_Layout.html`, in the worked example folder inside the Educational Publishing System project folder. The Ladder of Inference workbook, complete, cover to back cover, built and ruled page by page in the sitting.
2. **The Workbook Design Standard.** At the root of that same folder. Every ruling written out in words: page size, margins, every type size and weight, colour, the section icons, the running footer, the layout of each page, the back cover.
3. **DSRD 2 section 3.4**, corrected today, which still owns what a workbook says and now points at the design standard for how it looks.

**Precedence, and it matters: the template file wins.** Kain approved a rendered page, not a description of one. Where the written standard and the file disagree, the file is right and the standard is corrected. Where DSRD 2 and the design standard overlap, DSRD 2 owns words and the design standard owns appearance, and neither restates the other.

## 3. The changes that affect what you write, not just how it looks

Four of today's rulings change the copy a workbook carries. **These are the ones that reach your drafting.**

**The front cover no longer carries the lecture and course line, and no longer carries the how-to-use lines.** It carries the workbook title and **a short description of that workbook, written fresh for each one**, saying what it does for the reader. Three sentences or so. That description is a new per-workbook writing job and it did not exist before today.

**A new page sits between the cover and Part One: "Before you begin".** It carries the how-to-use lines, a tinted callout telling the reader to choose one real situation, and four writing lines so they record it and have it to hand.

**The lecture and course line has moved to the foot of that page, and its wording is now fixed:**

> This Achology workbook is designed to accompany lecture {n} of the
> **{Course name, linked to its course page}**
>
> *It will still be insightful for those not enrolled in this course.*

The course name is DSRD 5's canonical name, copied exactly. The second sentence is fixed copy on every workbook and is the line that says the workbook stands alone.

**The back cover no longer opens with "where this came from".** That block has moved to the before-you-begin page. The back cover now carries the community invitation and nothing else, laid out as two boxes headed **Discuss this topic in the forum** and **Discuss this topic in a group call**, a button reading **Join the Achology community**, and beneath it, small and italic, Kain's closing line verbatim:

> *The Achology community welcomes everyone interested in this topic. If you haven't participated yet, this is the place where these conversations take place.*

## 4. What has not changed

The five parts, their order, the word counts, the teaching at about 600 words, the exercise carrying one real situation through the model in the teaching's own order, five or six discussion questions about the idea, the base voice with no first person, the two permitted link destinations, the standalone test. All of it stands exactly as DSRD 2 section 3.4 has it.

**The exercise gains one visible rule from the design:** the gap between one step and the next is double the gap inside a step, so the reader can see where one question ends. That is layout, not writing, and the template handles it.

## 5. The cover image, ruled in principle and not yet built

Every cover will carry a photograph printed very faintly behind the title, so 24 workbooks do not look identical. The process Kain agreed:

- One image library of roughly fifty images, built by Kain, sized once, one naming pattern, one folder.
- **Each workbook's record names its image in one field.** One line, one filename.
- **A person chooses the image. Never at random.** A workbook on grief and a workbook on goal setting must not risk the same picture, and random means nobody is answerable when it reads wrong.
- One default image, so a cover can never ship blank.

**Nothing is asked of you on this yet.** The library does not exist and the field is not written. When it is, it will be one more line in the record.

## 6. Four things still open, named so nobody discovers them

1. Two of the four section icon paths were written from recollection and must be replaced with verbatim lucide-static data before any workbook ships.
2. The two logo images and the real course link are placeholders in the template file.
3. **The Data Labs pack still carries the old material** and has not been regenerated, so it does not yet reflect any of this.
4. **DSRD 2 says the instructor is named on the front cover. The approved cover names no instructor anywhere.** Either the cover gains an instructor line or that sentence goes. It is Kain's ruling and it is not made.

## 7. What is asked of you

**Nothing new to draft today.** This ruling exists so that the next workbook you are commissioned to write is drafted to the shape Kain approved rather than the one the old standard described.

**When a workbook run is commissioned:** read The Workbook Design Standard and open the template file before drafting. Write the cover description as a named job. Use the fixed source-line wording. Do not write a "where this came from" block on the back cover.

**If anything in DSRD 2 section 3.4 still contradicts the template**, say so in your batch report rather than choosing between them. Three such contradictions were found and corrected today, and finding a fourth would not be surprising.
