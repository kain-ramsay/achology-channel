# RULING: every page passes five stages before Kain is asked to sign it off (Kain, Code's S178 sitting, 21 October 2026)

**Kain's words:** "There needs to be a rule book that you keep somewhere for the process that we go through for approving a page. So on the workbooks page, we got the tidy up, the spacing, we got all the layout tweaks and changes, that I wanted made. And then I asked you ... to propose ten ways to make the page phenomenal ... Ten graphic design features that ... from a purely user experience, they just create visual excellence ... raised the page from like a 65 out of 100 to like a 92 out of 100. And I've not even seen the book pages you're asking me to sign off." And: "I hate having to repeat myself. I find this so tiresome."

**The five stages, in order:**
1. Tidy-up: the page's own code cleaned, no visible change, proved.
2. Kain's layout changes: four rendered options each, his pick recorded the moment he makes it.
3. The spacing check (RULING__A_Spacing_Check_Before_Every_Page_Sign_Off_S178), on the page as it stands; any later change cancels it.
4. Ten touches of visual excellence: ten graphic design touches that add no content but lift the experience, each played on the real page Before and After in Safari; Kain takes the ones he wants (as RULING__Workbook_Page_Ten_Touches_S178).
5. Walk-through: the page opened in new Safari tabs and walked through with him; only then the sign-off question.
