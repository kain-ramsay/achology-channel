## What that changes about the S283 rule set

`The_Standardisation_Rule_Set.md` is written and binding, and it is a **compliance pass**: run each description through the house rules and change only what those rules forbid. Karen's words stay Karen's words.

**Kain has now named a second purpose the rule set does not cover: these descriptions have to be found and cited.** A compliance pass makes a description acceptable. It does not make it answer a question a person types, and it does not give a language model a passage it can quote with attribution. Those are different jobs, and the second one changes what the text is for.

**So the rule set is not wrong, it is incomplete for what he now wants**, and running it as written would produce 2,146 compliant descriptions that then have to be rewritten. That is the round trip worth avoiding.

## What Code is asking Chat to settle, before commissioning anything

**One. What a lecture description is for, stated once.** Vimeo's copy of it is internal, since a student reads the description on the Achology page rather than in Vimeo. So the question is what the page needs, and Vimeo simply carries the same text.

**Two. Its shape.** Length, whether it opens with the question the lecture answers, whether it names the model or thinker taught in it, whether it closes with what the learner can do afterwards. The Help article standard already solved a version of this problem and is the obvious place to start rather than inventing a new one.

**Three. What makes it citeable rather than merely present.** A self-contained passage, a claim that stands without the video, the canonical name spelled out in full. Code has no authority over any of this and is not proposing it.

**Four. Where the output goes.** The rule set says `Standardised Description`, which is empty on all 2,146 rows. If the shape changes, say whether that column still holds the answer or whether a second column is wanted, so Karen's original stays readable beside it either way.

## What Code brings to it, so the brief can be sized

**Every description exists.** All 2,146 rows carry a `Lesson Description`. None carries a `Standardised Description`: the S283 pass has never been run.

**Code can run it at pace once commissioned**, in course sized batches with the original untouched beside every change, exactly as the rename ran.

**One constraint from the harness, so the brief lands cleanly.** Rule 8 says Code never drafts published words. Kain has ruled that this pass may be Code's, so the brief is what makes that lawful rather than a matter of interpretation: it should say plainly that it commissions Code to write the standardised descriptions, under the shape it sets.

## The one thing to avoid

**Do not commission a compliance pass and a rewrite as two passes over the same 2,146 rows.** Whatever shape is settled, apply it once. That is the whole reason this request exists rather than Code starting on the rule set as written.
