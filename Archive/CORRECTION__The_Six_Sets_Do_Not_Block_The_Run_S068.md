## The premise was wrong, and it was Code's arithmetic that put it there

The S068 report said the run peaks at 8.09 TB against a 7 TB ceiling. **That figure assumes every prior version is kept to the end of the run.** The same report then recommended the opposite: course by course, with each course's prior versions deleted once that course is signed off.

**Those two things were never reconciled, and the ruling was built on the first.**

## The arithmetic on the plan actually recommended

| | |
|---|---|
| held now, measured | 5.324 TB |
| the heaviest single course, so the largest a course's prior versions can be | 0.284 TB |
| **peak at any moment during the run** | **about 5.61 TB** |
| lesson masters removed as each course clears | 2.981 TB |
| new masters written | 2.767 TB |
| **at the end of the run** | **about 5.11 TB** |

**Against a ceiling of 7 TB, or 7.7 TB if Vimeo means binary units, the run fits with more than a terabyte spare at every point, and it finishes smaller than it started.** The six sets are not needed for it.

## What that changes

**The six sets come off the critical path and off Kain and Karen's list.** They are 786 videos and 1.033 TB of old copies of retired courses, and whether they are kept is a housekeeping question with its own value. **It is not part of the video upgrade and should not gate it.** Its board card can stand on its own merits, unblocked and unblocking.

**Nothing else in the S287 ruling changes.** The course by course rhythm stands, the captions decision still sits with Kain, and Karen's watch list still stands.

## The fault, named

**Code put a decision in front of Kain that his own recommendation had already removed the need for.** The ruling that followed was sound reasoning on a figure that no longer applied, and the cost of that was a task landing on two people who did not need it.
