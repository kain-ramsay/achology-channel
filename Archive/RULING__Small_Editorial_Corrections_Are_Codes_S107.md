# RULING: small editorial corrections are Code's, and do not travel to Chat

**DOCUMENT TYPE:** ruling, from Claude Code, Session 107. **Date:** Tuesday 8 September 2026. **Session type:** factory.
**Filed under Harness Rule 14.** This one narrows a standing rule, so it needs writing into the document that owns it rather than living in one session.
**Answers and closes:** `ASK__One_Of_The_Fifteen_Placements_Would_Lose_Its_Keyword_To_An_Apostrophe_S107.md`, same tray, which can be archived on arrival.
**Board cards:** the 250 help articles; the harness and instruction sets.

## 1. What happened

Code found that one of Cowork's fifteen help answer rewrites, post 10036, wrote the keyword with a curly apostrophe while the page's title and stored focus keyword both use a straight one. Applying it would have left Rank Math unable to see the keyword at all, so three tests the rewrite existed to fix would have stayed broken.

**Code held all fifteen and sent the question to Chat**, on the reading that an apostrophe inside a sentence a reader sees is a published word, and Harness Rule 8 puts published words outside Code's hands.

## 2. Kain's ruling, in his own words

> "Please just change the apostrophes and apply all fifteen right away Claude - small editorial tasks like this aren't something we need to put to chat"

**So the question should not have travelled.** It is filed here because the correction is to a rule, not to one page.

## 3. What Code takes from it, stated narrowly so it is not stretched

**Code may make a small editorial correction where the correct value is already fixed by something on the page or in the record, and no judgement about meaning is involved.** The apostrophe case is the type: the page's own title and keyword already said which character was right, so there was one correct answer and Code was reading it, not choosing it.

**What has not changed, and Code is not treating as loosened.** Writing or rewriting a sentence, changing what a sentence means, choosing a title, a heading, a blurb or metadata text, or deciding between two defensible wordings. Those still arrive written through the channel. **The test Code will apply: if a reasonable person could write it two ways, it is not Code's.**

**Where this leaves Rule 8.** Its sentence is unchanged for everything it was written to stop. What this ruling adds is that a mechanical correction to an already-decided value is not drafting, which is the same distinction Chat drew at S351 for heading markers: "A heading marker is not a written word... Harness Rule 8 stops you writing published words, not characters that decide a level."

## 4. What was actually changed on post 10036

**Two occurrences**, both of the keyword phrase: the opening sentence and the section heading. **Three other apostrophes in the same body were left exactly as Cowork wrote them**, because the ruling is about bringing the keyword phrase into line with its own page, not about typography across the article.

Every replacement was printed with the sentence around it before it was written, and all fifteen rows then passed Code's own four checks independently rather than on the rows' own verdicts.
