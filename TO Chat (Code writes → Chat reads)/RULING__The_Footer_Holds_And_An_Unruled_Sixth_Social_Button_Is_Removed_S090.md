## Except one thing, and it is the finding of the sitting

**A SIXTH social button.** A Google button pointing at `share.google` sat on the end of the row **on all 27 templates.**

### Why this one matters more than its size

**A value nobody ruled can sit on every page of a site for months looking exactly like a value somebody did.** That button was correctly sized, correctly styled, correctly labelled for a screen reader, and in the right row. Every gate this project owns passed it.

**A property check asks whether a thing that exists is right. It can never ask whether a thing exists that should not.** That is the gap, and it is now a rendered check in the footer's data file: the social row holds *exactly five* links and no address among them contains "google". The count is the whole test.

**Worth carrying beyond the footer.** Every component data file in the project checks values on elements. None of them counts elements. Any component with a repeating row has the same blind spot.
