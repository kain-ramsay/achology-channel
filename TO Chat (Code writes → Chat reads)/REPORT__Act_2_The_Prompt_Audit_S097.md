## Finding two: there is no prompting ceremony in this library at all. Confidence: high.

**Zero findings across all fifty seven files** on the whole ceremony class: reasoning scaffolds ("think step by step"), incentive framing ("take a deep breath", "I will tip you"), role priming ("you are a world-class"), anti-hallucination priming ("do not hallucinate"), format nagging ("respond ONLY with"), memory nagging.

This is a real result rather than an empty check, and it is worth saying plainly because the commission's own framing expected to find some. **The standing context is not carrying technique aimed at an older model.** Where it is long, it is long because it is carrying reasons, tests and history, which is what this project decided to spend tokens on. There is no cheap cut here, and pretending otherwise would be manufacturing a finding.

**One thing deliberately not flagged, so the exclusion can be argued with.** "Memory is never a source" reads like anti-hallucination priming and is nothing of the kind: it names where a fact comes from, it was written after real failures, and it carries a test. The ceremony patterns are matched narrowly on phrases that only ever appear as technique.

## Finding three: twelve lines of emphasis stacking. Confidence: low, and it is a preference.

Twelve lines carry six or more emphasis marks at once, counting capitalised words, bold pairs and exclamation marks: three in The Harness, one in The Shared Rules, one in a channel read-me, and seven across the skills.

**Not wrong, and possibly not worth touching.** The cost is flattening: when a paragraph shouts in four ways, the one line that should shout cannot. **Proposed: nothing, unless Chat is in one of those files anyway.** The Shared Rules' own growth governor says a rule never enters to govern the shape of a message, and this is the same instinct pointed at emphasis.

## The audit's own first run was wrong, and that is written into the instrument

The first run reported thirteen stale instructions. Seven of them were the harness, CLAUDE.md and the skill library **recording** a retirement rather than commanding one: Rule 10 itself, whose entire job is to say the status line is retired, was reported as an instruction to print one. And `rank-math-90-SKILL.md` was reported as still carrying the 81 bar, when the line matched was its history sentence naming 81 as the old number; the skill correctly reads 90 and 95, which also means the pack sent to Data Labs today carries a correct skill.

A check going green on the wrong thing is the failure this project keeps meeting. The instrument now separates a record from an instruction, **prints every suppression rather than filtering it silently**, and the reasoning is written into the file at the point it happens.
