# RULING: every Vimeo video is titled with its lesson number in front, matching Drive exactly

**DOCUMENT TYPE:** ruling, filed under Harness Rule 14. **From:** Claude Code, Session 068. **Date:** 19 August 2026.
**Given by:** Kain, directly in session, in answer to a question about whether the replacement should also retitle each video and carry its description into Vimeo.

---

## His words

> "Yes, put the number in front so that all file names are identical and so there can be no mistakes made"

## What it settles

**Every course video in Vimeo is retitled to its lesson number followed by its lesson name, taken from the twenty eight course CSVs, which are true north.** The form is the one Drive already carries: `NNN-NNN Lesson Name`, for example `016-006 Growing in Self-Awareness' Downloadable Resource`.

**One reading Code took rather than asking, and names here so it can be corrected in a line: the `.mp4` on the end is not carried into the title.** The number and the name are what make the two sides identical for matching; the extension is a file type marker rather than part of the name. Say the word and it goes in.

**Why he ruled it.** What Vimeo holds today is inconsistent to the point of being unusable as a check: some videos are titled only `001`, others `Copy of LC2 083 The SpiderWeb of Core Human Valu`, `MH Prac - 130final`, `COU62 Section 3 Summary- The Human Experience Ov`. With the number in front on both sides, any human or machine comparing Drive against Vimeo is comparing like with like, which is exactly the check that was impossible during the match.

**When it happens.** With the replacement, as part of the same pass, since both are writes to the same video and the token now carries the `edit` scope.

## What it does not settle, and what Chat needs to know

**Descriptions are held back, and there is a reason Chat owns.** The `Standardised Description` column in all twenty eight CSVs is **empty on all 2,146 rows**: the compliance pass defined by `The_Standardisation_Rule_Set.md` at S283 has never been run. Pushing descriptions into Vimeo today would push Karen's unchecked originals.

**So the sequence Code proposed and Kain accepted:** titles go up with the replacement, descriptions wait for the standardisation pass, then go up in one sweep afterwards. **The standardisation pass is content work and routes to Chat and Cowork, not to Code.**

**One fact worth carrying to the board:** a student reads the description on the Achology page, not the one in Vimeo. The Vimeo description is for the library's own use, which is why holding it back costs nothing.
