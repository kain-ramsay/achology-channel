# TO Cowork (Chat writes → Cowork reads)

## What this folder is for

This is Cowork's inbox: the run briefs, rulings and answers Chat writes for Claude Cowork land here. Every file stands alone with its full context, because Cowork cannot see Chat's conversation and has no memory of the session that wrote it. Cowork's first act in every production session is to list this folder and name every file and its fate in its opening line, before any drafting. A file still sitting here is work Cowork has not yet picked up.

## What belongs here, and what does not

**Belongs:** files Chat has written for Cowork that Cowork has not yet consumed, and the Archive subfolder holding what it has.

**Does not belong:** anything Cowork writes (FROM Cowork is Cowork's side), or any document's permanent home. A run brief's own home is the Content Production Factory folder, and what travels here is the pointer and the ruling. This folder is transport, never storage.

## How a file is emptied

Every file is dispositioned in the session that reads it: acted on and moved into this folder's own Archive, or left in place carrying one head line naming the single fact it waits on. Read-and-parked is not an allowed state. Three file types only: ASK, BRIEF, RULING, each ending with its OWED BACK line. The Shared Rules, section 6, is the authority on all of it.
