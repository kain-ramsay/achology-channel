## Write The Exemplar First, Then The Standard Out Of It

**The claim.** A standard written before the thing it governs exists can be internally perfect and still produce something worthless, because every check it contains measures the shape against itself. Write one real instance first, get it approved by the person whose judgement matters, then write the standard as a description of what was approved.

**What happened.** A workbook standard was written, ruled on, and installed in five places in one morning: five fixed headings, a word band, per-section guides whose sums matched the band's two ends, and a rule that the working section be at least half the document. The arithmetic was sound. Every automated check passed. The one workbook it produced taught its reader nothing and could not be worked through by anybody who had not just read a separate article, because the section that used to carry the teaching had been shrunk for a different reason and nothing put the teaching back.

Nobody in the system could have caught it. The gate counted words and headings. The specification described sections. The skill described the same sections. None of them asked what the document does for the person holding it.

**Why it is portable.** It is not about workbooks. It applies wherever a standard, schema, template or gate is written ahead of a real artefact: the checks inherit the author's model of the thing rather than testing it. The tell is a standard whose own examples are hypothetical.

**The practice.** Produce one real instance. Put it in front of the person who decides. Only then write the standard, and write it as a description of what was approved, naming the exemplar inside it so a later reader can check the standard against the thing rather than against itself. Where a quality check cannot be scripted, say so in the standard and name it as a human read.

**Related.** Volume Runs Only Against Frozen Exemplars (vault) is the same instinct applied to production; this is it applied one step earlier, to the standard itself.
