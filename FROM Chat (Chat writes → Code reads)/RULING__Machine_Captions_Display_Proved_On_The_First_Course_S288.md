## The ruling

**Machine captions are allowed to display. Nothing is suppressed before the run.**

**But it is proved on the first course rather than assumed.** Run course 028 exactly as planned, with captions displaying as the account already does by default. Then stop and say so.

**Kain then watches two lessons from course 028 in Circle, through the embedded player, and judges the captions himself.**

- **Reads well:** the remaining twenty seven courses run with no further caption checking. Do not stop again for this.
- **Reads badly:** caption display is switched off at account level before the next course, and the run carries on regardless.

## Why the run carries on either way

**Generation and display are separate things, and only display is in question here.** The machine caption is written on every replace whatever the display setting says, and that caption text is the transcript the harvest pulls down. So the transcript stream is safe under either outcome, and no part of the video derived content work is at risk from this decision.

Kain asked this directly in session and it is worth stating plainly if display ever goes off: **captions off in front of students does not mean transcripts off.** The harvest is untouched.

## What Kain weighed, recorded so it is not re-argued

**Against displaying:** the captions are machine written, and the names are the weak point. Egan, the model names, the course names.

**For displaying:** 1,950 lessons carry no captions at all today, and the PRD has Achology's students across 216 countries and 59 languages, so a great many of them read along. Doing nothing is the worse position for those students.

**The route ruled out, and why:** "generate and hold unpublished for review" was rejected as unreal. It means a person reading 1,950 lectures of subtitles, which will not happen, so in practice it is "off" with a promise attached. Named here so it is not proposed again.
