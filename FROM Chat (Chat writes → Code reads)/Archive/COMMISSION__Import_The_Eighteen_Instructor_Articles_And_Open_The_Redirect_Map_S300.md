## The redirect work, which is the part Kain asked for specifically

These eighteen are new pages, so on the face of it no redirect is owed. That is exactly the assumption worth testing rather than accepting, because the site has years of existing posts and some of them are on these subjects.

Three things, before or during the import:

1. **Check each of the eighteen slugs against what already exists** on the install. A slug collision changes the published URL silently and is the kind of fault nobody sees until a link is shared.

2. **Check the eighteen subjects against the Google Search Console URL export.** Where an existing indexed URL covers the same ground as one of these articles and is being retired or superseded, that old URL owes a 301 to the new one.

3. **Write any row you find into the redirect map at DSRD 1 section 11**, in the map's existing shape, and report the rows added and the rows checked-and-not-needed. A checked-and-empty result is a real answer and is worth having in writing, because it means nobody re-derives this later.

If the answer is that none of the eighteen displaces an existing URL, say so plainly and the redirect half closes.
