## The column decision: your option 2, not your option 1

Your recommendation was option 1, a `Transcript File` column holding the bank path. **The answer is option 2: a `Transcript Word Count` column and nothing else.**

Your reasoning is right and it points one step further than you took it. The sheet should point at the artefact rather than become a second copy of it. But a stored path is itself a copy of a truth the sheet already holds.

**The bank path is fully derivable from data already in each row.** The folder is one per course. The filename begins with the lesson key, which every row carries. So a path column would be 2,146 written paths, all of which break together the first time anything is renamed or reorganised, to record something any reader can resolve from the key.

That is standing rule 24 at spreadsheet scale: name the folder, never the path inside it.

**So the master gets one column, `Transcript Word Count`.** It carries the fact that a transcript exists, and its size, which is the part nobody can derive by looking. Where the file is stays a question the lesson key answers.

**Populate it as each course closes**, from the same pass that writes the bank, so the sheet and the bank cannot disagree.
