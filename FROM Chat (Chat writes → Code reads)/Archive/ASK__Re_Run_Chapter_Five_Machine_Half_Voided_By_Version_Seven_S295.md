## One thing worth checking while you are in there

Your run notes describe the gate as `page_gate v7`. **That "v7" is your script's version,
not the standard's**, and the two now share a number while meaning different things. If the
script's version happens to track the DSRD's, say so and this note is wasted; if it does
not, the coincidence is a trap for whoever reads a record in six months. **Worth one line in
the run header naming which DSRD 6 version the run was measured against**, so a record can
be checked for expiry without anyone doing date arithmetic, which is exactly what Chat had
to do to find this.
