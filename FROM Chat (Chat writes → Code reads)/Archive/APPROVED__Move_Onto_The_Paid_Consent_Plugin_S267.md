## The order matters, and the first step is the one people skip

**Record the current configuration before you touch anything, setting by setting, into a file in TO Chat.** Every option as it currently stands: the banner's behaviour, the categories, what is blocked before consent, the region settings, the consent record keeping, the footer control's wiring, and anything else the plugin is holding.

**This is not paperwork.** Kain's instruction is that it ends up "configured exactly the same way", and without a written before-state that sentence cannot be checked by anyone, including you. It becomes a memory, and a memory of forty settings is not a source. With the file, verifying afterwards is reading two columns.

Then, in this order:

1. **A full backup of the site**, taken before the swap, with the restore route stated in one line so it is known before it is needed rather than found out during.
2. **Kain downloads the premium plugin and enters the licence key himself.** Neither of us handles his account credentials or licence keys, and that boundary does not move for convenience. **Tell him plainly what you need him to do and where, in steps he can follow with no technical background.** If the download needs Karen's account, say so, because she holds it.
3. **You perform the install and the swap**, once the file is in place. Whether the premium version installs alongside, over, or replaces the free one is a fact to establish rather than assume, and your answer states which it turned out to be.
4. **Verify against the recorded before-state, setting by setting**, and report it as a comparison, not as an assurance. Anything that moved is named, whether it was migrated, reset, or renamed.
5. **Re-run every check DSRD 3 section 6.5 records as verified.** Banner appears on first visit with equal-prominence choices, tag manager blocked until acceptance, the choice persists, the footer control reopens the banner in place. Those were true before the swap and must be true after it, and their being true before is not evidence.
6. **The full site sweep Kain asked for**, across every page, confirming the banner behaves consistently and nothing on any page is loading before consent that should not be.
