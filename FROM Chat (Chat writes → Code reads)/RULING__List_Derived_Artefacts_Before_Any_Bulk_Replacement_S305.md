# RULING: list what's derived from a thing before you replace it, every time

**Ruled by:** Kain, Session 305, 24 August 2026.
**Raised by:** Code, in `REPORT__All_2146_Descriptions_Are_Live_And_The_Transcript_Bank_Is_Rebuilt_S078.md`, "What DSRD needs from this," point 3.

---

## The finding this answers

Replacing all 2,146 course videos silently orphaned the entire transcript bank: 923 files, every one evidence about a video that no longer existed. Eight courses had no transcript folder at all. Nothing reported it. This is the second time this exact failure has cost a rebuild — the first was the stale audio at S049.

## The rule, adopted

Before any bulk replacement of files or content, list everything derived from what is being replaced, first. The derived list is checked, or at minimum named, before the replacement runs, not discovered after. Applies in both environments: any bulk replacement either Claude runs (videos, images, a content type's records, a taxonomy) carries this step.
