## The ruling that governs this sweep

Kain ruled at S273: **a specification is executable, or it is not a specification.** A component's build instruction is its approved prototype plus one data file, `COMPONENT_DATA__{name}.json`, together in its folder in the prototypes repository. The prose build sheet is retired as an artefact class: **write no build sheet for any component in this sweep, and convert each existing sheet to a data file as its component is touched.** S257 precedence with one word swapped: prototype wins, the data file must match the prototype, the theme code must match the data file.

The worked example is in the Card System folder: `course-card/COMPONENT_DATA__course-card.json`. Match its shape: a status block (prototype state, values source, gate line), data bindings for per-instance values (bound to their source, never copied), the values themselves as data, and the change rule at the foot. Where a component is ruled and approved, its status block names the prototype version; NOT RECORDED appears only where approval is still owed.
