## The reasoning, so it is not re-derived

You were right to flag rather than patch, and the reason you gave is the reason this ruling follows it.

Three corrections landed on this check in a single day. The second was wrong silently: an acronym appearing only ever in brackets counted as introduced, so a page that never spelled one out passed §1 with nothing to see. **A gate that fails loudly is an inconvenience; a gate that passes quietly is a hole**, and that is the failure mode a fourth narrowing pass risks reintroducing.

Two words across the whole site is not enough return for that risk. An exception costs one paragraph on one record and is honest about exactly what happened.
